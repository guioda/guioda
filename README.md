## Sobre mim

Oi! Sou o Guilherme Oda, desenvolvedor .NET com foco em backend. Trabalho principalmente com C#, construindo APIs e lidando com bancos de dados relacionais.

No front end, uso Blazor WebAssembly para criar as interfaces, o que me permite trabalhar com C# de ponta a ponta, do banco de dados até a tela.

Gosto de entender como os sistemas funcionam por dentro, organizar bem o código e transformar requisitos em algo que funcione de verdade.

- Construindo aplicações backend com C# e .NET
- Desenvolvendo interfaces web com Blazor WebAssembly
